# Bank Data Center – Cisco Packet Tracer Lab

This project is a production-style bank data center network built in Cisco Packet Tracer 8.1, designed to simulate a secure and scalable enterprise banking infrastructure using advanced Cisco networking technologies.

The topology follows a multi-tier architecture that includes ISP connectivity, core routing, firewall security layers, aggregation switches, and access switches supporting multiple VLANs and enterprise services. Unlike the first version, this implementation uses routers instead of dedicated load balancer servers to handle traffic distribution and routing operations.

The network includes Cisco 2911 routers, Layer 3 and Layer 2 switches, ASA firewalls, and security systems such as SOC, SIEM, IDS, IPS, and database services. Key technologies implemented include OSPF, BGP, HSRP, VLAN segmentation, NAT/PAT, ACLs, and QoS to provide redundancy, secure communication, and optimized traffic management.

Security is reinforced through a DMZ-based firewall architecture with strict access control policies and protected database communication. The project demonstrates enterprise-level routing, network segmentation, failover mechanisms, and layered security commonly found in modern banking data centers.

This lab is suitable for CCNA/CCNP practice, cybersecurity learning, enterprise network simulations, and hands-on experience with real-world Cisco infrastructure design.
